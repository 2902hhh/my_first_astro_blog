# Sequence Containers

## vectors

**一个可以动态调整大小的、内存连续的数组**

```cpp
#include <vector>

int main()
{
	std::vector<int> vec {1,2,3,4};

}
```

**注意**：`[]`用来访问数组元素时，不会自动检查越界，即虽然 `vec {1,2,3,4}`,只有4个元素，使用 `vec[4]`不会报错，属于未定义行为。使用 `vec.at()`则会检查是否越界。

练习：找最大值

```cpp
#include <iostream>
#include <vector>

/* Returns highest temperature,
   or -1 if no temperatures given. */
int findPeakHeat(const std::vector<int>& temps) {
    // Write your implementation here.
    int peak;
    for(auto & temp : temps)
    {
        if(temp >= peak )
        peak = temp;
    }
  
    return peak;
  
}

int main() {
    // High temperatures forecast for the next 7 days.
    std::vector<int> weeklyForecast = {82, 95, 102, 99, 88, 79, 81};

    std::cout << "--- Weather Report ---" << std::endl;
    std::cout << "Max temp this week will be " << findPeakHeat(weeklyForecast) << std::endl;
    return 0;
}
```

# Associative Containers

**关联容器实现了一种有序的数据结构，可以对其中的数据进行高效查找**

## maps

**map 存储由键（Key）和值（Value）组成的键值对，并且每个键都是唯一的**

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores;

    scores["Alice"] = 95;
    scores["Bob"] = 88;
    scores["Charlie"] = 92;

    std::cout << scores["Bob"];
}

```

map的标准初始化格式

```cpp
#include <map>
int mian()
{
	std::map<int,char> preston {
	{16,'p'}, {18, 'r'}, {5,'e'}
	}

	for(auto & pair : preston)
	{
		std::cout << pair.first << ' ' << pair.second << std::endl; //eg pair.first即为16，pair.secomd即为p
	
	}
}
```

map与pair的关系

`std::map` **是一个容器，而** `std::pair` **是这个容器中每个元素的数据类型**，也就是说，`map` **由一系列** `pair` **组成，每个** `pair` **保存一个 Key（键）和一个 Value（值）**

`std::pair` 是 C++ 标准库提供的一种数据类型，可以把两个值组合在一起

```cpp
std::pair<int,char> p{16,'p'};
```

`map`里装着的就是一系列 `pair`

**当使用** `map[key]` **访问一个不存在的 Key 时，**`map` **会自动插入这个 Key，并为它创建一个默认初始化的 Value**

map的一些用法

```cpp
std::map<char,int> m;
m.insert({k,v});

m[k] = v;

m.erase(k);

if(m.count(k)) // 是否有k

if(m.empty()) //是否为空

```

综合练习

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <map>
#include <set>

// TODO: Implement this function
// Find all employees that appear in more than one department.
std::set<std::string> findDoubleAgents(std::map<std::string, std::set<std::string>> departments) {
    std::set<std::string> seen;
    std::set<std::string> doubleAgents;

    // Your code here
    for (auto & pair : departments)
    {
        for(auto & name_set : pair.second)
        {
            if(!(seen.insert(name_set)).second)
            {
                doubleAgents.insert(name_set);
            }
        }
    }
  
  
    return doubleAgents;
}

int main() {
    std::map<std::string, std::set<std::string>> company = {
        {"Sales", {"Jim", "Dwight", "Phyllis"}},
        {"Accounting", {"Angela", "Oscar", "Kevin"}},
        {"Pranks", {"Jim", "Pam"}}
    };

    std::set<std::string> multiTaskers = findDoubleAgents(company);

    std::cout << "Double Agents: ";
    for (auto name : multiTaskers) std::cout << name << " "; // Should print Jim
    std::cout << std::endl;

    return 0;
}
```

`!seen.insert(name_set)` 的问题在于：`std::set::insert()` **的返回值不是** `bool`**，而是一个** `std::pair`**，因此不能直接使用逻辑非运算符** `!`

`std::set`的返回值类型是 `std::pair<std::set<T>::iterator, bool>`

* `result.first`：指向对应元素的迭代器
* `result.second`：表示是否成功插入，类型为 `bool`
  则当有重复的元素试图插入 `set`中时，会无法插入并且 `bool`返回 `false`，就可以利用这种方式判断是否有重复元素

**有序关联容器（Associative Containers）的两个重要知识点**：

1. `set` 和 `map` 都有允许重复键的版本：`multiset` 和 `multimap`。
2. 有序关联容器必须能够比较元素（或者 Key）的大小，才能维持排序，所以一些无法比较的数据类型如 `std::ifstream`就无法使用有序关联容器

关于 `multimap`和 `map`

```cpp
std::multimap<int, std::string> students;

students.insert({1, "Alice"});
students.insert({1, "Bob"}); //可以插入两个1
```

关于 `multiset`和 `set`

```cpp
std::set<int> s{3, 1, 3, 2};
std::multiset<int> ms{3, 1, 3, 2};
//遍历结果
//set:      1 2 3
//multiset: 1 2 3 3
```

`map`和 `set`都会自动排序，`multiset` 和 `multimap`也是如此

# Unordered Associative Containers

`map` to `unordered_map`
`set` to `unordered_set`

通过计算 Key 的哈希值来组织数据，通常使用哈希表
**哈希函数将一个 Key 经过某种计算，转换为一个** `size_t` **类型的整数**
**Key 必须能够计算哈希值，并且能够判断两个 Key 是否相等**

无序关联容器不会对数据进行排序，它的查找速度一般优于有序关联容器
