# Iterator Basics

我们需要一个东西来让我们知道我们现在在容器里的哪个位置，这就是迭代器所想要实现的功能

`container.begin()`，让一个迭代器指向首个元素
`container.end()` , 让一个迭代器指向最后一个元素的后一个位置

如果一个容器是空的，则这两者是指向相同的位置

```cpp
auto it = c.begin();

++it;

auto & elem = *it;

if(it==c.end())
```

所以要遍历 `set`这样的无法使用 `[]`的容器，则可以使用

```cpp
std::set<int> s{1,2,3,4};

for(auto it=s.begin();it != s.end(); ++it)
{
	const auto& elem = *it;
}
//it 的类型是
std::map<int,int>::iterator it;

```

这实际上就是

```cpp
for(auto elem : s)
{
	std::cout << elem;
}
```

的工作原理

# Iterator Types

所有的迭代器都至少有这四个功能

```cpp
auto it = c.begin();

++it;

auto & elem = *it;

if(it==c.end())
```

## input iterators

迭代器不止可以用于遍历容器，也可以用来一次读取输入流中的数据

```cpp
#include <iterator>
#include <iostream>

int main() {
    std::istream_iterator<int> it(std::cin); //从cin中读取数据
    std::istream_iterator<int> end;

    while (it != end) {
        std::cout << *it << " ";
        ++it;
    }

    return 0;
}
```

如果元素是一个结构体 `struct`，则可以使用 `->`来取得它的成员

## output iterator

```cpp
#include <vector>
#include <iterator>
#include <iostream>

int main() {
    std::vector<int> v;

    std::back_insert_iterator<std::vector<int>> it(v);

    *it = 10;  // calls v.push_back(10)
    ++it;

    *it = 20;  // calls v.push_back(20)
    ++it;

    *it = 30;  // calls v.push_back(30)

    // v is now {10, 20, 30}
    return 0;
}
```

`std::back_insert_iterator` 用于**向容器写入数据**
**对于** `back_insert_iterator`**，执行** `*it = value`**，实际上就是调用容器的** `push_back(value)`

## forward iterator

**Forward Iterator 允许我们保存多个迭代器，并且反复遍历同一段数据**

但是，输入流的典型特点就是数据顺序到达、被消费后不能依靠普通流迭代器重新访问

# Pointers and Memory

迭代器指向一个容器的元素，指针则指向任意的对象

每一个变量都在内存中占据着一个地方

要想获得这个变量在内存中的地址，就需要用到指针

```cpp
int x = 106;
int* px = &x; //int * 表示这是一个指向int类型的指针；& 则是取地址

std::cout << x << std::endl; // 106
std::cout << *px << std::endl; // 106
std::cout << px << std::endl; // 0x50527c（内存地址）
```
