# Classes

面向对象编程 OOP
面向对象编程以对象为中心，通过设计类来组织数据和功能
类由用户自定义，可以根绝类来创建对象

容器就是在标准模板库中被定义的类

`struct` 可以认为是没有权限限制的 `classes`

`classes`中有 `private` `public`

```cpp
class ClassName {
private:


public:


}

```

外部可以自由访问 `public`的部分

关于头文件 `.h`和源文件 `.cpp`

| 对比项   | 头文件 `.h`                        | 源文件 `.cpp`                 |
| -------- | ------------------------------------ | ------------------------------- |
| 用途     | 定义接口                             | 实现类的成员函数                |
| 包含内容 | 函数声明、类声明、类型定义、宏、常量 | 函数实现、可执行代码            |
| 使用方式 | 被多个源文件共享使用                 | 被编译为目标文件                |
| 示例     | `void someFunction();`             | `void someFunction() { ... }` |

一个类通常由四个部分组成

* 构造函数
* 私有成员
* 公有成员
* 析构函数

构造函数 Constructor

```cpp
// .h文件
class StanfordID{
private:
	std::string name;
	std::string sunet;
	int idNumber;

public:
	//整个类的构造函数
	StanfordID(std::string name, std::string sunet, int idNumber);

	std::string getName();
	std::string getSunet();
	int getID();
}

```

在源文件里

```cpp
//.cpp文件
#include  "StanfordID.h"

//析构函数 会自动调用
```

```cpp
/* File: wizard.cpp
 * Author: Preston Seay
 * 
 * This file contains practice for implementing a wizard
 * and spellbook class, as well as provides a main function
 * that can run some methods of the classes for you.
 * 
 * As an exercise, implement the wizard and spellbook
 * classes and run the program.
 */
#include <iostream>
#include <string>
#include <map>
#include "wizard.h"

// ==========================
// =     CLASS 1: Wizard    =
// ==========================

// This constructor creates a new wizard, storing it's name
// and starting energy.
Wizard::Wizard(const std::string& name, int energy) {
    this->name = name;
    this->energy = energy;
}

// This function will try to use `amount` of energy.
// If the wizard has enough energy to decrease by
// amount and still be non-zero, then it will subtract
// from energy and return true. Otherwise, the energy
// should remain unchanged and it will return false.
bool Wizard::useEnergy(int amount) {
  
    if(this->energy > amount)
    {
        this->energy = this->energy - amount;
        return true;
    }
    else
        return false;

}

// This function should simply return the amount of energy
// the wizard has left.
int Wizard::getEnergy() const {
    return this->energy;
}

// This should simply return the name of the wizard.
std::string Wizard::getName() const {
    return this->name;
}

// ==========================
// =   CLASS 2: SpellBook   =
// ==========================

// Add this spell to the spellbook.
void SpellBook::addSpell(const std::string& name, int cost) {
    (this->spells).insert({name,cost}) ;
}

// Try to have the wizard cast all of the spells they can.
void SpellBook::castAll(Wizard& w) {
   for (auto & pair : this->spells)
   {
       w.useEnergy(pair.second);
   }
}

// ==========================
// =        MAIN TEST       =
// ==========================
int main() {
    Wizard w("Merlin", 50);
    SpellBook book;

    book.addSpell("Fireball", 20);
    book.addSpell("Ice", 35);
    book.addSpell("Storm", 15);

    book.castAll(w);

    std::cout << w.getName()
              << " has " << w.getEnergy()
              << " energy left\n";
}
```

```cpp
/* File: wizard.h
 * Author: Preston Seay
 *
 * This file defines a Wizard and a SpellBook class.
 * The wizard has a certain amount of energy, and each spellbook
 * requires a certain amount of energy to cast.
 * 
 * Note that the energy level of the wizard is private because
 * we don't want anyone to be able to change that and it can be
 * non negative and decrease. That's called encapsulation.
 * 
 */
#include <iostream>
#include <string>
#include <map>

class Wizard {
private:
    std::string name;
    int energy;

public:
    Wizard(const std::string& name, int energy);

    bool useEnergy(int amount);   // subtract if possible, return success
    int getEnergy() const;
    std::string getName() const;
};

class SpellBook {
private:
    std::map<std::string, int> spells; // spell -> cost

public:
    void addSpell(const std::string& name, int cost);
    void castAll(Wizard& w); // iterate over map and try to cast everything
};
```

# Inheritance

不同种类的类也许会需要相同的接口，继承可以扩展一个类使其具有特定的性质

```cpp
//.h
class Shape {
public:
	virtual double area() const = 0; //纯虚函数，基类不提供实现，由派生类实现
} 

class Circle : public Shape { //定义一个circle类，继承自Shape
public:
	Circle(double radius): _radius{radius} {};
	double area() const {                 //重新定义了area，这有点像stm32里对中断函数的重写
		return 3.14 * _radius * _radius;
	}

private:
	double _radius;
}

```

继承有不同的类型
`public`  `private`  `protected`
`class` 默认私有继承，`struct` 默认公有继承
这三种继承会影响基类的成员在派生类的中的成员类别

# Virtuality

虚继承用来解决多重继承问题
当

```cpp
class A {
public:
    int value = 10;
};

class B : public A {};

class C : public A {};

class D : public B, public C {};

```

D同时继承B，C，当我要访问 `d.value`时，这个变量有B从A那里继承来的，也有C从A那里继承来的，就会出现冲突，要解决这类冲突就要用到虚继承，也就是让B，C虚继承A

```cpp
class A {
public:
    int value = 10;
};

class B : virtual public A {};

class C : virtual public A {}; //会使得B和C共用一份A基类的子对象

class D : public B, public C {};
```

`virtual`和 `public`这些解决的是不同的问题，可以组合使用
`virtual public`
